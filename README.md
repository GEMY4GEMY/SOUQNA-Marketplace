# SOUQNA Marketplace

Local-first classifieds marketplace, starting with Fayoum, Egypt.

## Architecture
- Web/PWA storefront
- Marketplace API
- PostgreSQL-ready data model
- Role-based access control
- Owner Control Center
- Moderation and audit logging
- Multi-governorate expansion

## Environments
Development → Staging → Production

## Security
No production secrets, passwords, payment keys, or database credentials are committed to this repository.

## Initial roles
SUPER_OWNER → ADMIN → MODERATOR / SUPPORT → BUSINESS → USER
