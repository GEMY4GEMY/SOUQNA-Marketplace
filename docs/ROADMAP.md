# SOUQNA Roadmap

## Phase 1 — Foundation
- Next.js + TypeScript
- PostgreSQL/Prisma data model
- Arabic RTL responsive shell
- roles and permission model
- Fayoum-first, multi-governorate architecture

## Phase 2 — Marketplace
- registration/login
- phone verification
- create/edit/delete ads
- image uploads
- category-specific fields
- search/filter/sort
- favorites
- seller profile

## Phase 3 — Owner Control Center
- operational dashboard
- ads moderation
- users/staff
- categories and locations
- packages/pricing
- reports and audit log
- platform settings

## Phase 4 — Trust & Communication
- reports
- chat
- notifications
- anti-spam/rate limits
- seller/business verification

## Phase 5 — Monetization
- featured/top ads
- dealer subscriptions
- coupons/promotions
- payment provider integration
- transaction ledger

## Phase 6 — Launch
- staging QA
- security review
- backups/restore test
- analytics/monitoring
- production deployment
- PWA readiness
